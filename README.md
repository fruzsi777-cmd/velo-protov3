# Vela – interactive prototype

Coded rebuild of the Figma section **Kulcsképernyők_V2** (🟦 Vela project). Plain HTML/CSS/JS, no build step, all files flat in the repo root.

**Flow:** Onboarding (swipe / auto-advance) → Home → Bitcoin position → Modify → Long / Short ticket → slide to open → Position opened → Home

**Interactions:** count-up numbers, live price ticks, charts that draw in, scrub (drag) and morph between time ranges, segmented tabs, swipeable open trades & news, dismissable news cards, watchlist star, feed reorder, Feed/Stats tabs, draggable leverage with live total/liquidation/fee, % presets, number keypad, slide-to-confirm, thesis sheet, floating 3D glass objects with parallax.

Deep links: `/#/1` … `/#/9` · press **R** to restart.
